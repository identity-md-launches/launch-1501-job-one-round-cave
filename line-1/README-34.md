Ethereum observation without silently selecting between duplicate JSON keys
or reading an unbounded/outside file. Its README has an offline demonstration,
real ZTO capture details, tests and operational limits. GOAL.md is unchanged.

carry to another worker. The full wall is `artifacts/line-1/wall-v15.png`, with
an identical continuing copy at `artifacts/line-1/wall.png`: 1254×1254, 8-bit RGB
PNG, 3,837,530 bytes. Record `dist/line-1/34.json` binds its SHA-256;
`dist/line-1/34.jpg` is a 512×512 baseline JPEG, 62,129 bytes.

with the installed image tool, inspected it, and used ffmpeg plus an adapted
Line 1 finalizer to blend only its charcoal and ochre into vacant upper-right
rock. The insert was overwritten with the finished wall; no extra image is
retained. Exact pixel comparison found 3,727 changed pixels inside
(810,125,115,140), none outside. The final PNG and JPEG were inspected visually
and structurally. Five digits remain on each inherited hand. There are no new
hands or stencils, and no text. No known unmet visual requirement; inherited
photographic-looking rock and the motif's small thumbnail size are limitations.
See `wall-review-34.json` for dimensions, preservation and visual findings.

real ZTO snapshot at block 26180977 sealed and verified offline. There was no
